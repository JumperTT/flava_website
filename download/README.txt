  Flava Download — 使用说明

【重要】如何正确启动（否则会 Failed to fetch）
------------------------------------------------------------

本项目所有下载方式都依赖 fetch() 动态获取真实文件，
因此浏览器要求服务器必须返回 CORS 头。

✅ 唯一正确方式：用本项目自带的 Node 服务器

    cd 到项目目录
    node server.js

    默认端口 5500，浏览器打开 http://localhost:5500

    也可以自定义端口：node server.js 8080

❌ 以下方式都会失败，不要使用：

    ✗ VS Code Live Server（端口 5500 但无 CORS 头）
    ✗ python -m http.server（无 CORS 头）
    ✗ 双击 index.html（file:// 协议禁止 fetch）

    如果你看到 "Failed to fetch" 错误，99% 是你用了上面
    三种方式之一。请改用 node server.js。

------------------------------------------------------------
【文件结构】
------------------------------------------------------------

  index.html              页面主体
  style.css               样式
  bg-animation.js         背景动画
  download-dialog.js      弹窗 + 四种下载逻辑（零 fallback）
  server.js               Node 服务器（CORS + Range）
  verify.js               端到端验证脚本
  download/
    └── flava.exe         真实安装包（请替换为此文件）

------------------------------------------------------------
【替换真实安装包】
------------------------------------------------------------

把你的真实 flava.exe 放到 download/ 文件夹，
覆盖原来的占位文件即可。无需修改任何代码，
服务器会自动读取文件真实大小。

------------------------------------------------------------
【四种下载方式】
------------------------------------------------------------

  1. 直接下载       → <a download> 触发浏览器下载
  2. 写入文件       → File System Access API（Chrome/Edge）
  3. Base64 复制    → 编码到只读文本框，一键复制
  4. Base64 拖拽    → 编码到可编辑文本框，手动复制

  方式 3/4 使用 FileReader.readAsDataURL 编码，
  支持任意大小文件，无栈溢出风险。

------------------------------------------------------------
【验证】
------------------------------------------------------------

  node verify.js

  会启动服务器 → fetch 文件 → Base64 编码 →
  与 Python 标准库交叉验证 → 确认可逆。
