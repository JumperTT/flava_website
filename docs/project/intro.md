# 项目介绍

## 关于 Flava

Flava 是一个现代 Web 项目，致力于提供极致的用户体验。

## 核心特性

| 特性 | 说明 |
|------|------|
| 纯静态 | 无需后端，部署极简 |
| 暗色主题 | 护眼配色 + 火焰动效 |
| 响应式 | 适配桌面与移动端 |
| 零构建 | 写完 Markdown 即发布 |

## 技术栈

- **前端框架**: 原生 JavaScript（无框架依赖）
- **文档引擎**: docsify v5
- **动画**: Canvas 2D API
- **样式**: 纯 CSS（含 backdrop-filter 毛玻璃效果）

## 快速开始

```bash
# 克隆项目
git clone https://github.com/yourname/flava.git

# 进入目录
cd flava

# 使用任意静态服务器即可
npx serve .
```

> 💡 也可以直接双击 `index.html` 在浏览器中打开（部分浏览器需 `--allow-file-access-from-files`）。
