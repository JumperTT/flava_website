# 设计文档

```

│           index.html                │
│  ┌─────────┐  ┌─────────────────┐  │
│  │ 顶部导航 │  │   侧边栏菜单    │  │
│  └─────────┘  └─────────────────┘  │

│  │   Canvas 背景层（网格+火焰）  │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
```

## 视觉设计

### 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色调 | `#ff4500` | 火焰橙，用于强调和交互 |
| 辅助色 | `#ff8c42` | 浅橙，用于链接和标题 |
| 背景色 | `#000000` | 纯黑底色 |
| 文字主色 | `#e0e0e0` | 高对比度灰白 |
| 文字次色 | `rgba(255,255,255,0.7)` | 侧边栏次级文字 |

### 动画原理

1. **旋转网格**：Canvas 绘制两层网格（20px 暗色 + 10px 亮色），整体旋转 30°
2. **火焰光晕**：三层贝塞尔曲线（红/橙/黄）叠加，每帧随机扰动控制点
3. **漂浮粒子**：从底部向上飘动，带正弦摆动和透明度衰减

## 响应式策略

- 桌面端：侧边栏固定 220px，内容区自适应
- 移动端：侧边栏抽屉式，点击菜单图标滑出
