### flava extra 1.0 帮助文档 Lua 端 API

---

flava 的拓展系统使用完整的 Lua 5.4 作为脚本解释器，每个 flava 程序会共享所有全局变量，即使单个脚本结束也不会清除全局变量。你不用手动编译脚本，flava 自己会编译。

以下是所有的 API 及使用说明：

#### 1. `flava.log`

| 项目 | 说明 |
|------|------|
| 输入 | 日志内容（字符串） |
| 输出 | 状态码（整数） |
| 内容 | 在日志区输出日志。返回 `0` 表示成功，`1` 表示缺少/多余参数，`2` 表示参数类型错误 |

```lua
flava.log("这是一条日志")
```

---

#### 2. `flava.widget_set_visibility`

| 项目 | 说明 |
|------|------|
| 输入 | 控件标签（字符串）；可见性（布尔值） |
| 输出 | 状态码（整数） |
| 内容 | 修改控件可见性。返回 `0` 成功，`1` 缺少/多余参数，`2` 参数类型错误，`3` 不存在的 label |

```lua
flava.widget_set_visibility("Button1", false)
```

---

#### 3. `flava.widget_set_text`

| 项目 | 说明 |
|------|------|
| 输入 | 控件标签（字符串）；文字（字符串） |
| 输出 | 状态码（整数） |
| 内容 | 修改控件文字。返回 `0` 成功，`1` 缺少/多余参数，`2` 参数类型错误，`3` 不存在的 label |

```lua
flava.widget_set_text("Text1", "新文字内容")
```

---

#### 4. `flava.canvas_create_rect`

| 项目 | 说明 |
|------|------|
| 输入 | x1, y1, x2, y2（整数）；r, g, b, a（整数）；是否实心（布尔值） |
| 输出 | 状态码（整数） |
| 内容 | **只能在 Canvas 绘制回调中使用**。在 `(x1,y1)` 到 `(x2,y2)` 范围内绘制矩形。返回 `0` 成功，`1` 缺少/多余参数，`2` 参数类型错误，`3` 不在 Canvas 绘制回调 |

```lua
flava.canvas_create_rect(10, 10, 100, 50, 255, 0, 0, 255, true)
```

---

#### 5. `flava.canvas_create_line`

| 项目 | 说明 |
|------|------|
| 输入 | x1, y1, x2, y2（整数）；r, g, b, a（整数）；线宽 d（整数） |
| 输出 | 状态码（整数） |
| 内容 | **只能在 Canvas 绘制回调中使用**。绘制从 `(x1,y1)` 到 `(x2,y2)` 的线段。返回 `0` 成功，`1` 缺少/多余参数，`2` 参数类型错误，`3` 不在 Canvas 绘制回调 |

```lua
flava.canvas_create_line(0, 0, 100, 100, 0, 255, 0, 255, 2)
```

---

#### 6. `flava.canvas_create_circle`

| 项目 | 说明 |
|------|------|
| 输入 | x1, y1（整数）；rx, ry（整数）；r, g, b, a（整数）；是否实心（布尔值） |
| 输出 | 状态码（整数） |
| 内容 | **只能在 Canvas 绘制回调中使用**。以 `(x1,y1)` 为圆心，`rx` 为横轴半径，`ry` 为纵轴半径绘制圆/椭圆。返回 `0` 成功，`1` 缺少/多余参数，`2` 参数类型错误，`3` 不在 Canvas 绘制回调 |

```lua
flava.canvas_create_circle(50, 50, 20, 20, 0, 0, 255, 255, true)
```

---

#### 7. `flava.canvas_get_mouse_state`

| 项目 | 说明 |
|------|------|
| 输入 | 鼠标按键（字符串） |
| 输出 | 状态码（整数） |
| 内容 | **只能在 Canvas 绘制回调中使用**。查询鼠标按键状态。传入 `right` 代表右键，`left` 代表左键 |

返回值说明：

| 返回值 | 含义 |
|--------|------|
| `0` | 刚按下 |
| `1` | 持续按下 |
| `2` | 刚松开 |
| `3` | 没有按下 |
| `-1` | 缺少/多余参数 |
| `-2` | 参数类型错误 |
| `-3` | 不在 Canvas 绘制回调 |
| `-4` | 传入的不是 right 或 left |

```lua
local state = flava.canvas_get_mouse_state("left")
```

---

#### 8. `flava.canvas_get_mouse_x`

| 项目 | 说明 |
|------|------|
| 输入 | 无 |
| 输出 | x 坐标或状态码 |
| 内容 | **只能在 Canvas 绘制回调中使用**。返回鼠标 x 坐标，不在 Canvas 回调时返回 `-1` |

```lua
local mx = flava.canvas_get_mouse_x()
```

#### 10. `flava.get_keyboard_state`

| 项目 | 说明 |
|------|------|
| 输入 | 按键 ID（整数） |
| 输出 | 状态码（整数） |
| 内容 | 查询键盘按键状态 |

返回值说明：

| 返回值 | 含义 |
|--------|------|
| `0` | 刚按下瞬间 |
| `1` | 正在按下 |
| `2` | 刚松开瞬间 |
| `-1` | 缺少/多余参数 |
| `-2` | 参数类型错误 |

> 按键 ID 参考 `keys.md`

```lua
local keyState = flava.get_keyboard_state(525) -- 查询 Enter 键
```
