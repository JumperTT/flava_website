### flava extra 1.0 帮助文档 `.ui` 文件

---

flava 本身是 Dear ImGui 程序，flava 的拓展系统使用 `.ui` 文件来储存控件信息，它是自定义格式的，规则如下：

#### 1. 控件格式

每一行代表一个控件，格式为：

```
控件名:标签名;文字;回调;是否显示;宽度;长度
```

| 字段 | 说明 |
|------|------|
| 标签名 | 所有拓展中唯一的，不能重复，**必填**！不填会导致 flava 闪退 |
| 文字 | 控件显示的文字，只对特定控件生效 |
| 回调 | 当发生事件时执行的 lua 文件，不同控件执行条件不同，不包含后缀名 |
| 是否显示 | 是否绘制文字，可以后续修改，对所有控件生效，填 `true` 或 `false` |
| 宽度/长度 | 控件的长宽，只对特定控件生效 |

#### 2. 缩进与分组

如果你需要控件在同一行或者一个组内，flava 采用缩进格式，规则如下：

- 同一行的控件使用 `Line` 标志
- 同一组的控件使用 `Group` 标志
- 标志后不写任何东西，换行后缩进任意长度的空格，新建的控件会在同一行或组内
- 结束该行或组需要结束该级缩进

示例：

```uifile
Text:1;a;;true
Line
 Button:2;b;AAA;true
 Button:3;c;BBB;true
 Group
  Button:4;d;CCC;true
  Button:5;e;DDD;true
Text:6;f;;true
```

效果示意：

```text
a
[b] [c] [d]
    [e]
f
```

#### 3. 目前支持的所有控件

- **Text**（文字）：`Text:标签;文字内容;留空;是否显示`
- **Button**（按钮）：`Button:标签;文字内容;点击回调文件;是否显示`
- **Canvas**（画布）：`Canvas:标签;留空;绘制回调文件（每一帧绘制时调用）;是否显示;宽度;长度`
