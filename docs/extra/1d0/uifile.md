\### flava extra 1.0帮助文档 .ui文件

\-----

flava本身是DearImGui程序，flava的拓展系统使用.ui文件来储存控件信息，它是自定义格式的，规则如下：
1. 每一行代表一个控件，格式为：
控件名:标签名;文字;回调;是否显示;宽度;长度
其中标签名是所有拓展中唯一的，不能重复，必填！不填会导致flava闪退；
文字表示控件显示的文字，只对特定控件生效；
回调是当发生事件时执行的lua文件，不同控件执行条件不同，不包含后缀名；
是否显示表示是否绘制文字，可以后续修改，对所有控件生效，填true或false；
宽度，长度表示控件的长宽，只对特定控件生效
2. 如果你需要控件在同一行或者一个组内，flava采用缩进格式，规则如下：
同一行的控件使用Line标志，同一组的控件使用Group标志，标志后不写任何东西，换行后缩进任意长度的空格后新建的控件会在同一行或组内，结束该行或组需要结束改级缩进，举例：

```uifile
Text:1;a;;true
Line
 Button:2;b;AAA;true
 Button:3;c;BBB;true
 Group
  Button:4;d;CCC;true
  Button:5;e;DDD;true
Text:6;f;;true

```
该示例的效果如下（示意）

```text
a
\[b] \[c] \[d]
    \[e]
f

```
3. 目前支持的所有控件：
- 文字 Text:标签;文字内容;留空;是否显示
- 按钮 Button:标签;文字内容;点击回调文件;是否显示
- 画布 Canvas:标签;留空;绘制回调文件（每一帧绘制时调用）;是否显示;宽度;长度
