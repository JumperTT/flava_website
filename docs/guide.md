# 用户手册

## 快速上手

欢迎使用 Flava！本手册将帮助你快速掌握核心功能。

## 基本操作

### 浏览文档

1. 打开文档站首页
2. 点击左上角 **☰ 菜单图标** 展开侧边栏
3. 选择你想阅读的文档分类
4. 点击具体文档标题即可查看内容

### 搜索文档

- 在页面顶部搜索框中输入关键词
- 实时显示匹配结果
- 点击结果项直接跳转

### 快捷操作

| 操作 | 快捷键 |
|------|--------|
| 展开/收起侧边栏 | 点击 ☰ 图标 |
| 返回首页 | 点击侧边栏「← 返回主页」 |
| 刷新内容 | `F5` / `Ctrl+R` |

## 常见问题

### 页面显示异常？

尝试以下操作：
1. 清除浏览器缓存（`Ctrl+Shift+Del`）
2. 确认浏览器版本符合要求
3. 检查网络连接是否正常

### 搜索无结果？

- 确认关键词拼写正确
- 尝试使用更短的关键词
- 部分文档可能尚未被索引，稍后再试

### 如何反馈问题？

1. 前往 [GitHub Issues](https://github.com/yourname/flava/issues) 提交反馈
2. 或通过 B 站私信联系开发者
